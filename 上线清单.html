若按钮还没出现：多数情况是要等微信认证通过后才放开，先把下面两步的资料备齐。
✓

主体证件（营业执照 / 身份证，须与认证主体一致）、负责人身份证正反面（四角完整、无反光）、负责人手机号与邮箱。
大部分字段会由系统从认证资料自动预填，逐一核对即可；最后用负责人微信扫码做人脸核验。
✓

各省通信管理局效率不同，常见区间为数个工作日到数周。通过后后台备案页会显示「已备案」与备案号，此时才具备正式对外发布的资格。

⚠ 千万别把 AppSecret 当成上传密钥（实测踩过）
这两个东西长得完全不像，却常常搞混：
AppSecret —— 32 位十六进制字符串，用于服务端调用微信 API（如 code2session），不能用于上传。
代码上传密钥 —— 后台下载的一个 PEM 私钥文件，内容以 -----BEGIN 开头，文件名形如 private.wx….key。
拿错会报：generate local signature fail … private key file is incorrect。脚本现在会自动识别并提示，体检脚本也会校验格式。
安全：AppSecret 属于最高敏感凭证，一旦外泄请立即在「开发设置 → AppSecret」点重置，旧密钥当场失效。
⚠ 第二个坑：IP 白名单（实测也踩过）
生成上传密钥时如果配了 IP 白名单，只有名单内的网络能上传，其余一律报 errCode -10008 invalid ip: x.x.x.x。
报错里那个 IP 就是微信看到的当前出口 IP，把它加进去即可：「开发管理 → 开发设置 → 小程序代码上传密钥 → IP 白名单」。
实测教训（2026-10-10）：同一个网络，前后 40 分钟出口 IP 就变了 —— 124.77.206.127 → 124.77.168.97。
所以别单个 IP 一个个加：首选直接清空白名单（不限制来源）；次选加整个网段（如 124.77.0.0/16，格式以后台该处提示为准）。
命令行里加了 --no-proxy 可以绕开系统代理，用来确认「到底是本机 IP 还是代理出口 IP」。

为什么不能直接在 mp 后台网页上传？
微信公众平台后台只管版本，不管传代码 —— 开发管理页面可以设体验版、提交审核、查看 AppID 与上传密钥，但代码包必须由开发者工具或官方 CI 工具 miniprogram-ci推上去。
另外，后台每一步都需要管理员微信扫码，这部分没人能代劳。所以：上传可以一条命令搞定，设为体验版 / 提交审核仍需你本人在后台点几下。
