微信小程序 · 效果预览稿

这是用小程序同一份数据（data/*.js）渲染出来的浏览器预览，用于快速确认视觉与交互。 正式交付物是微信小程序工程，用微信开发者工具导入本目录即可运行。

  • 族谱：家族 → 辈分分层，头像节点 + 连线，点击进详情
  • 全阵容：演员表全景 + 关键词搜索
  • 角色详情：介绍 / 演员 / 人物关系（可跳转）
  • 历史参考：韩粱 → 于谦，可互相跳转
  • 剧情介绍：点顶部 Banner 进入，左右 Tab 切换 —— 分集剧情（逐集故事）｜ 礼学整理（人胜 / 彩胜 / 及笄礼 / 和离 / 大明律…按分类归组）
