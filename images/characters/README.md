# 角色头像目录（images/characters/）

## 当前状态

本目录下的 24 张头像为 **AI 生成的古风工笔示意图**（非真实剧照），
覆盖 24 位主要角色（领衔主演 5 + 主要演员 1 + 主要配角 18）。

其余 110 位非主要角色使用 `images/generic/` 下的 6 张通用头像，
按「性别 × 年龄段」区分（墨色白描剪影，透明底，家族色圆底透出）。

## 替换为真实剧照

把剧照按 **角色 id** 命名覆盖本目录同名文件即可，无需改任何代码。

```
images/characters/shen_jialan.jpg    → 沈嘉兰（谭松韵）
images/characters/lin_jinqi.jpg      → 林锦岐（刘学义）
images/characters/han_liang.jpg      → 韩粱（牛骏峰）
images/characters/zhao_xingtang.jpg  → 赵星棠（李梦）
images/characters/du_cuique.jpg      → 杜翠雀（郑合惠子）
... 其余 19 张同理
```

完整 id 清单见 `data/characters.js` 每个角色的 `id` 字段。
规格建议：正方形 ≥400×400，单张 <100KB，全部合计 <1.5MB。

## 三级兜底机制（不会出现破图）

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 本目录本地图片 | 打包进小程序，随包发布 |
| 2 | `images/generic/` 通用头像 | 非主要角色按性别 + 年龄段共用 |
| 3 | 自动降级 | 用「角色姓氏首字 + 家族主题色」生成古风印章头像 |

## ⚠️ 版权与合规提醒

1. **AI 生成内容需标识**：根据《人工智能生成合成内容标识办法》及平台要求，
   AI 生成内容需显著标识。当前已在首页脚注、角色详情页脚注与本文件中声明，
   **提审前建议在角色详情页头像旁增加「AI 生成示意图」标识**。
2. **演员肖像权**：AI 头像若与演员真人高度相似可能涉及肖像权。
   生成时的 prompt 已刻意避免指向特定真人，**上线前建议人工复核这 24 张，
   过于肖似演员本人的应重绘或替换**。
3. **剧照版权归原版权方（腾讯视频 / 星莲影视）所有**，未经授权打包进公开上线的小程序存在侵权风险。
4. 若使用远程 URL：图片域名必须在小程序管理后台「开发 → 开发设置 → 服务器域名」中配置为合法域名。
